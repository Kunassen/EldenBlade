## 当前成品没有达到概念图的原因

1. 概念图是生成的二维表现，反光、雕刻、血纹厚度并不自动成为模型结构。我没有逐项完成对应的几何、专用 UV 与明暗贴图。
2. 当前刀身、刀鞘采用连续截面扫掠，护手与绳结主要由规则形状组合，缺少概念图的结构和细节节奏。增加面数只让轮廓更圆，不能代替造型设计。
3. 通用材质压成长条、再映射到窄刀面，高频细节在小屏幕尺寸下变成噪点。纹理没有随刀根、刀腹、刀尖、刀鞘装具组织。
4. 缺少刻意绘制的宽窄高光、缝隙阴影、边缘磨损与局部发光。2048 分辨率本身不足以产生质感。
5. 离线预览仅做颜色采样和深度排序，没有真实游戏光照。之前没有完成实际客户端的手持、佩戴、多角度和缩小尺寸验收，还误判了刃口方向。

这属于此前制作方法与验收不足，不应把差距归咎于 Minecraft 无法表现精细刀剑。不能承诺把二维概念图的全部光照直接复制进游戏。改进需要重新设计具体截面和装饰、按部位展开 UV、绘制贴合形状的纹理，再用实际模型和客户端验证；不能仅继续替换通用材质。
