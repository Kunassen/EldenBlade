# 1.0.0 — 2026-10-19

- 新增 Shift 悬停老翁描述，鲜红色 #FF2020，按原文分行和空行显示。
- 客户端专用事件订阅，服务器基础回归通过。
- 整理公开源码与发布 JAR，清理过时产物、测试世界和日志，脱敏文档及预览图元数据。
- 构建基线默认重锋 1.1.23，移除固定本机 JDK 路径。

#.4.0-alpha — 2026-10-17

- 新增每存档服务器配置 eldenblade-server.toml，配置默认攻击力、SA 每段最大生命百分比、SE 触发概率/百分比/冷却。
- 新增管理员 config 指令，修改后即时生效并保存；attack 指令可覆盖手中尸山血海的基础攻击力，reset 恢复默认。
- 命令获取和合成输出应用配置；已有玩家背包内未独立覆盖的刀同步默认攻击力，其他刀不受影响。
- SA 在释放时固定此次两段的百分比，SE 使用判定时配置，所有百分比参数以 10 = 10% 表示。
- 默认数值、外观、范围、耐久、初始附魔及材料配方保持。

# 0.3.1-alpha — 2026-10-17

- 修正银白刃口方向，六点截面的磨刃面移动到正 Y 侧。
- 刀与刀鞘长度缩为 0.3.0 的 7/8，完整刀长由 415 调整为 363.125；宽厚保持。
- 只修正上述两项，不把整体美术差距描述为已解决。

# 0.3.0-alpha — 2026-10-17

采用用户选定的 B 尸骨祭坛背景。长度 ×1.25，截面宽厚 ×1.20；刀鞘两端偏黑、中段泛白，刀身新增双面银白磨刃面；补充立体柄绳、刀镡边缘、布结及垂带。图集升级为 2048×2048，替换三张绘制表面素材。物品栏背景限于图标模型分组，沿用重锋耐久框；图标长度独立适配。

本版只调整外观资源与生成工具，不改变战斗与合成代码。旧刀无需重新获取即可使用新外观。

# 0.2.0-alpha — 2026-10-17

- 增加指定九宫格配方，分别检查阎魔刀 200/10/5000、木偶 20/5/2000 的击杀/锻造/耀魂门槛。
- 配方继承材料刀数值，同时保留输出五项 X 级默认附魔，修复原生配方会降级超限附魔的问题。
- 新刀最大耐久 779；初始锋利、抢夺、力量、火焰附加、耐久 X。
- 尸横遍野范围扩大为前方 7×7×7；伤害系数及 SE 不变。
- 两段分别生成红色原生刀光，交叉倾角、挥斩声与红色粒子；不给视觉实体设置 shooter，避免额外伤害。
- 重绘不规则血纹与刀鞘风化材质，增加立体鞘口绳结；持刀、刀鞘、破损及物品栏分组共用完整贴图。
- 不重写玩家已有刀的 NBT，新默认属性需重新获取刀。未修改用户整合包或存档。

# 0.1.1-alpha — 2026-10-17

修复落幕曲 1.6.3fix 启动时的 Forge 版本拒绝：整合包使用 Forge 47.3.22，0.1.0-alpha 的 mods.toml 却要求 [47.4,)，导致模组代码尚未加载就退出。

- Forge 运行依赖范围改为 [47.3.22,48)。
- 默认 Forge 编译基线降到 47.3.22，支持 -PforgeVersion 选择基线。
- 版本号升为 0.1.1-alpha，避免与旧文件混淆。
- 本次不改变武器、SA、SE 数值及模型。

此前的重锋 1.1.23 测试使用 Forge 47.4.23，未覆盖落幕曲实际的 47.3.22，这是首版验证遗漏。
