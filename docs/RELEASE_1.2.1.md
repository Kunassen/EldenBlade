# EldenBlade 1.2.1 — 重锋版本兼容扩展

日期：2026-10-23。

## 改动

- 将重锋依赖范围从 `[1.1.23,1.9)` 扩展为 `[1.1.23,1.9.65]`，包含用户提供的 1.8.62、1.9.63、1.9.64、1.9.65，并保留旧版 1.1.23。
- 沿用 1.1.23 的公共接口编译，不引入新版本专有方法；无需修改技能逻辑或资产。
- 新增 `tools/test_slashblade_versions.ps1`：编译依赖固定为 1.1.23，仅替换运行依赖，检查跨版本二进制兼容。运行依赖使用内容完全相同的本地别名，避免 ForgeGradle 合并两个版本。
- 配置文件、合成要求、模型、音效、SA／SE 数值及生命值识别逻辑不变。

## 安装

使用 `releases/EldenBlade-1.20.1-1.2.1.jar` 替换旧版。需要 Minecraft 1.20.1、Java 17、Forge 47.3.22 或兼容的更高 47.x。客户端和服务端都更新，同一实例只安装一个重锋 JAR。无需删除配置或重新获取武器。

## 验证范围

测试使用 Forge 47.3.22 / Java 17，隔离存档；不修改用户整合包与存档。每个版本执行 16 项 GameTest，其中两个外部 Boss 检查因未安装对应模组而跳过，实际功能测试为 14 项。覆盖武器默认值、附魔与耐久、合成门槛和继承、两段 SA、SE 冷却、数值配置与指令、斩击几何、原版与自定义同步生命值识别、死亡流程及拒绝不明确存储。

运行矩阵结果：1.1.23、1.8.62、1.9.63、1.9.64、1.9.65 均通过全部 16 项必需测试（其中各有两个外部 Boss 检查跳过）。五次运行均使用相同的已编译类，日志中的 `compileJava UP-TO-DATE` 确认未随运行依赖重新编译。

客户端验证：在 1.9.65 下进入复制的开发测试世界，自动执行五次 SA，捕获 575 帧，检查第三人称多方向及第一人称画面，模型与两道血光可见，客户端正常退出。日志为 `build/compat-client-1.9.65.log`。重锋自身的模型 JSON 存在 `slashblade:user` 字符串谓词解析报错（相关资源路径属于重锋）；此轮未改写第三方资源。未对每个版本分别进行客户端多视角检查，未进行完整整合包或多人联机回归。
