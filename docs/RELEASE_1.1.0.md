# 1.1.0：尸横遍野血光与音效

成品：`releases/EldenBlade-1.20.1-1.1.0.jar`，5,324,792 字节。

SHA256：`0399ba65106d6f4d5e8efeeabab79847354174136840c543d981a0b291ca3835`。

最终按重锋 1.1.23 基线执行 `build` 成功。`tools/verify_release.py` 已检查 JAR 完整性、
1.1.0 版本、六行描述、血光 RGBA 纹理、两段单声道 Vorbis、模型资源一致性以及测试辅助类排除。

本次将 SA 的原版横扫声、通用 SlashBlade 刀光和两排红色粒子，替换为专用弧形血光与用户视频中的挥斩声。武器本体、合成、配置键及伤害比例不变。

## 行为

- 第一道血光斜向展开，第二道反向交叉，均有血丝、透明缺口、拖尾和淡出。
- 两段间隔从 3 tick 改为 5 tick；20 TPS 下为 0.25 秒。原有第一段动作速度随之调整。
- 每道视觉实体存活 12 tick；32 个四边形、64 三角面，最多两道同时存在。
- 同一张 2172×724 RGBA 纹理复用；基础纹理显存约 6 MiB，不增加武器本体面数。
- 自发光颜色不依赖环境亮度，不产生动态照明。渲染写入深度，避免云层穿过血光。
- 视觉实体无攻击、碰撞、推挤或存档行为。服务端仍独立计算每段 150% 攻击属性伤害和配置的最大生命百分比。
- 使用 Forge 实体同步传播位置、朝向、段序和出生时刻；晚收到的效果按世界时间计算剩余寿命。
- 两段音频分别为 0.25 秒和 1.10 秒，44.1 kHz 单声道 Vorbis，声音随距离衰减。

## 本地复现

先运行 `runGameTestServer -PrunDir=run-sa-test`，再把已关闭的测试世界
`run-sa-test/world` 复制到 `run-sa-client/saves/sa-preview`。
运行 `runClient -PrunDir=run-sa-client -PvisualDemo` 会在该测试世界自动触发三次 SA、
采集 `run-sa-client/screenshots/sa-*.png`，随后退出。
请仅对专门的测试世界启用该开关，因为捕获工具会搭建平台并改变时间与测试玩家位置。

资源来源、处理参数和血光生成提示词见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。
